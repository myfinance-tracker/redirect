# Finance Tracker — bank sign-in redirect

After a bank approval through Enable Banking, the browser lands on this page, which opens the Finance
Tracker app (`financetracker://enablebanking-callback`) with the result. Served with GitHub Pages at
https://myfinance-tracker.github.io/redirect/ — every Enable Banking registration used with the app must
list that address as a redirect URL. Also holds the app's privacy policy and terms of use.
